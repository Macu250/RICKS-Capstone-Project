Chronic Pain Management - RICKS
This project aims to help manage chronic pain, not through direct medical care but by allowing those who are more experienced with the process use it to help themselves. By using a variety of resources and tools the goal is to create a tool to be used and not something that must be used by the medically trained.

Release Notes:
The current workings include the navigation bar and most of the timer. Most other functions are limited in scope or empty. Currently it is run by local host while next development should allow running simply through a browser. Currently not ready for mobile use.

Navigation bar is the main branch currently. Cleaning up the GitHub is not the priority but is on the docket to be finished.
